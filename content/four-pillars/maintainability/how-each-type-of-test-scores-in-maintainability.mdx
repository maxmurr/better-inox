A test's **maintainability** reflects how easy it is to read, change, and set
up. Here is how frontend test types compare:

```
|             | Maintainability           |
|-------------|---------------------------|
| Unit        | High (= easy to maintain) |
| Integration | Medium                    |
| E2E         | Low (= hard to maintain)  |
```

**Unit tests.** They score **high** because they usually need little setup and
are easier to keep short and readable.

**Integration tests.** They score **medium** because they cover more of a use
case and require more dependencies and setup.

**E2E tests.** They score **low** because they require the most setup and are
harder to write and change.

These scores describe the built-in maintenance cost of each test type. They do
not excuse unclear integration or E2E tests. Their higher cost makes readable,
concise tests even more important.
