The previous lesson compared two tests. The first used
[Cypress](https://www.cypress.io) to cover a user journey. The second passed an
input to a function and checked its output:

- **Test case 1** reproduces user actions, intercepts an API request, and checks
  local storage.
- **Test case 2** passes an input to a function and checks its output.

The second test is easier to understand and change because it has fewer
**out-of-process dependencies**. External storage, API configuration, and
database cleanup all add maintenance work.

A test's **maintainability** depends on two attributes:

- Readability
- Ease of setup
