Unit tests cover small pieces of an application, such as functions, classes, or
groups of them. This close connection to production code can make unit tests
more brittle than higher-level tests. Valuable unit tests avoid implementation
details.

The _createQuizModel()_ function creates and validates the quiz fields:

```ts
export function createQuizModel(form: QuizForm): QuizModel {
  // Validation below
  const validatedTitle = validateTitle(form);
  const validatedQuestions = validateQuestions(form);
  const maybeError = validateAnswers(
    validatedQuestions.flatMap((q) => q.answers)
  );
  if (maybeError instanceof Error) {
    throw answersOrError;
  }

  return {
    title: validatedTitle,
    questions: validatedQuestions,
  };
}
```

We could unit-test any of these functions:

- _validateTitle()_ function
- _validateQuestions()_ function
- _validateAnswers()_ function
- _createQuizModel()_ function
