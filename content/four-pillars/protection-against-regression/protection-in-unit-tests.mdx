Now that we know what protection against regressions means, we can discuss how
each type of test in the Pyramid scores in that pillar. So, let's start with
**Unit Tests** (tests that don't communicate with out-of-process dependencies).

Suppose we're developing a web application that helps build quizzes for all
sorts of purposes - online courses, games, feedback forms, etc. Our current task
is to develop the page that creates new quizzes, which should look like this:

There are many pieces of code that we can decide to create a test for — let's
list them below:

1. Test for a utility function that validates the image URL.
2. Test for the factory function that creates a Quiz as a whole.
3. Test for the questions' initial state object, which could look something like
   this:

```tsx
const [questions, setQuestions] = useState<Question[]>([
  {
    heading: '',
    imageUrl: '',
    questionType: 'single',
    answers: [],
  },
]);
```
