Let's compare how each test type protects against regressions, starting with
**unit tests**. Unit tests do not communicate with out-of-process dependencies.

Suppose we are building a quiz app for courses, games, and feedback forms. Our
current task is a page for creating quizzes:

We could test several pieces of this page:

1. A utility function that validates the image URL.
2. The factory function that creates a complete quiz.
3. The initial state for questions:

```tsx
const [questions, setQuestions] = useState<Question[]>([
  {
    heading: '',
    imageUrl: '',
    questionType: 'single',
    answers: [],
  },
]);
```
