A **regression** is a bug that breaks behavior that used to work. It can happen
when we add a feature or refactor existing code.

As a codebase grows, it often gains more hidden coupling and unexpected
interactions. A small change can then break several features and make future
changes expensive.

**Good automated tests** catch these breaks early. They let us keep changing the
system as it grows.
